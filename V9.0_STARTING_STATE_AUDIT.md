## 7. Blockers / Constraints for V9.0

1. **v8.12 baseline frozen** — no modifying/retraining/contaminating locked artifacts.
2. **No tuning on APTOS locked test or IDRiD test** — locked test = final single-shot only. Referral threshold 0.78104581 is validation-derived, not test-tuned.
3. **Messidor-2 labels not official** — cannot be a primary clinical-validation claim; use for robustness + third-party-label sanity.
4. **Lesion/NV/localization pipeline not clinically credible in v8.12** — v9.0 must either improve (within sprint) or present as HONEST NEGATIVE with clear scope labels.
5. **SimEvents absent** — no queue-simulation claims; only Simulink operational model.
6. **CV/Stats/Medical Imaging toolboxes absent in MATLAB** — MATLAB work must rely on Image Processing + Deep Learning toolboxes; no claims requiring absent toolboxes.
7. **Sensitivity gap** — referable sens 0.8956 must reach >0.90 without trading away specificity >0.85 on the SAME validation scope v8.12 reported.
8. **No saved Grad-CAM demo artifacts** — explainability demo must be (re)generated in v9.0.
9. **No clinical validation performed** — "AI proposes, clinician disposes"; never claim clinical validation.
