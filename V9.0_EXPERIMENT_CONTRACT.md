# V9.0 EXPERIMENT CONTRACT

**Project:** SIH26038 — Explainable AI for Diabetic Retinopathy Screening in Rural India
**Branch:** v9.0 (experimental). **Frozen baseline:** v8.12 (never modified/retrained/contaminated).
**Deadline:** 30 Sep 2026 (submission sprint). **Contract date:** 24 Sep 2026.

This document is the binding plan for all v9.0 experiments. Any deviation must be justified in the experiment log with evidence tags.

---

## 1. Objective
Beat or match the frozen v8.12 clinical envelope on the SAME validation scope, and turn the current gap (referable sensitivity 0.8956 vs PS >0.90) into a met target, WITHOUT tuning on APTOS locked test or IDRiD official test. Then produce the explainability + MATLAB + Simulink + ablation artifacts the PS requires.

## 2. Scope

### In scope (sprint)
- v9.0 experiment X1–X3 (below) using **copies** of frozen v8.12 artifacts.
- Re-baseline checkpoint: train/copy the v8.12 architecture on the SAME locked split (or load frozen ckpt) ⇒ baseline metrics re-issued under v9.0 scope labels.
- Quality gate + review-pathway demo (PS 1a–1c).
- Saved Grad-CAM demo set.
- Annotated report demo ("AI proposes, clinician disposes"; no clinical validation claim).
- Clean A/B/C/D ablation table (PS 6b).
- Simulink re-run with v9.0 numbers; MATLAB ONNX parity re-check.
- Messidor-2 robustness transfer probe (THIRD_PARTY_LABELED scope).

### Out of scope / NOT NEEDED this sprint
- FGADR and any NEOVASCULARIZATION dataset acquisition.
- Clinical validation / patient trials / IRB work.
- SimEvents / MATLAB CVT / MIT / SMTL toolboxes (not installed).
- Any research-paper writing.
- Tuning on APTOS locked test or IDRiD official test (final single-shot only).

## 3. Fixed datasets & splits (locked once, reused everywhere)
| Dataset | Split / usage rule |
|---|---|
| APTOS train | locked internal train/val split per `locked_split_ids_v8_12.json` (frozen). All training/validation in X1–X3 happens here. |

## 4. Guardrails (non-negotiable)
1. v8.12 artifacts are read-only. Trained models go under `sih26038_v9_0\checkpoints\`.
2. No item-level inspection of locked test before the single final run.
3. Referral threshold 0.78104581 is validation-derived; never claimed as test-tuned.
4. Every metric in any report carries a scope label: `APTOS_VAL` / `APTOS_LOCKED_TEST` / `IDRiD_TEST` / `THIRD_PARTY_MESSIDOR2` / `DRIVE_DEV` + evidence tag.
5. Lesion segmentation (MA 0.000 / EX 0.008 / HE 0.000 / SE 0.024) and localizer (median err 1014–1073 px) are HONEST_NEGATIVE unless improved; no fabricated boosting.
6. "AI proposes, clinician disposes" — no clinician validation claim without an actual validated protocol.

## 8. Winning / failing gates
- **Met:** APTOS_VAL ref-sens > 0.90 AND ref-spec > 0.85 AND QWK ≥ 0.90; Grad-CAM demo set saved; ablation table clean; MATLAB parity + Simulink re-issued under v9.0; all reports carry scope labels.
- **Frozen-fallback:** if X2 fails gates, submission uses v8.12 numbers with honest scope labels and v9.0 improvements documented as next-iteration.
- **Hard-fail:** any item-level tuning on locked test, any fabricated clinical validation, any unlabeled Messidor claim, any regression of spec below 0.85 presented as an improvement.
